# v1.4 price and liquidity update

## What changed in the build

1. **Dollar-anchored game prices:** the displayed cosmetic remains $4–$12 USDG equivalent. A fresh RIVAL quote calculates token units from a bounded external price feed. Testnet continues using an explicitly labeled mock tariff.
2. **Before mainnet RIVAL quote or price proof:** the server checks the independently fetched o1 token detail for chain 4663, the configured canonical token, USDG quote, exact pool ID, `fresh` observation no older than 30 seconds, USDG reference within $0.98–$1.02, at least $50,000 indexed USD liquidity, and o1 price within 2% of the external feed. Missing or contradictory data means no RIVAL quote. USDG checkout is independent. This is a **trusted, indexed check**, not an executable buy/sell quote.
3. **At RIVAL purchase:** the store's EIP-712 version 2 requires an order-specific signer-attested spot within 3% of the original signed quote. The observation can be at most 20 seconds old, with five seconds of permitted block-clock skew. Without the proof, with an expired/forged proof, or after a large move seen before proof issuance, the contract rejects **before the ERC-20 transfer**. A proof can expire while a wallet is open, costing gas if broadcast anyway. The signer and feeds remain trust assumptions; a market move after attestation can still occur before inclusion. There is no independent onchain TWAP oracle.
4. **Economy page:** it now reads and labels o1's indexed RIVAL price and USD pool liquidity estimate, with an as-of time, block and change since the previous recorded observation. If there is no launched token, read key or fresh observation it displays **unavailable**, not invented TVL or zero. The SQLite observation table retains snapshots across server restarts. The old store cannot accept the new order and proof types; deploy v1.4 bytecode and run `preflight`.

## Why this does not automatically increase TVL

o1 Standard's locked, single-sided Uniswap v4 position initially receives all 1 billion RIVAL and **no creator-deposited USDG**. Buyers add USDG to that pool and sellers withdraw it. Its Hook owns the locked position; **outside accounts cannot modify or add to it**. The o1 indexed USD liquidity metric can rise or fall as inventory and price change. Its value is not a stablecoin reserve, exit guarantee, or the game's operating cash. [o1 single-sided liquidity](https://docs.o1.exchange/launchpad/trading/liquidity) · [o1 token-details API](https://docs.o1.exchange/launchpad/public-api/reference/tokens/get-token-details)

With the illustrative 10,000-MAU, 3%-payer, $8-spend and 50%-RIVAL cohort, token checkout is $1,200 equivalent; $240 is retired at quote time and $960 in tokens reaches treasury. If all buyers newly acquire RIVAL and the treasury sells its receipts, the simplified net flow is **+$240 of buys**. If buyers pay from balances and the treasury sells, it is **−$960 of sells**. If treasury holds, +$1,200 of new buys could add paired assets but the treasury bears token-price and operating-cost risk. These are flows **before fees, price impact and other trading**; none predicts a TVL or price percentage. A separate Uniswap pool or staking program would require capital, different contracts, security work and a genuinely funded reward budget. This build does not manufacture TVL, automate buybacks or create staking rewards.

## Deployment boundary

This package has local EVM and mocked o1 API tests. It has **no o1 API key, canonical token address, mainnet pool, Robinhood testnet receipts or real mobile wallet timing evidence**. Start with USDG checkout. Verify o1 market depth and the price service, exercise quote → approval → price proof → purchase on funded testnet wallets, then review security and execution risk before considering mainnet RIVAL checkout. Current $50,000 indexed-liquidity gate is deliberately conservative but cannot alone make checkout safe.
